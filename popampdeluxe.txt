  2026-11-20   HIDE FILE EXTENSION, AND AN ICON FOR PLAYLISTS
  ..........................................................................

  Preferences > Media Library > Hide file extension

  Ticked (the default): the Foldertree writes every file name without its
  extension: .mp3, .flac, .m3u, .pls and so on. Not ticked: every file shows
  its extension. The change shows at once.

  Playlist files (.m3u, .m3u8, .pls, .xspf) now have an icon of their own, a
  small page with lines, in front of the name. Folders keep the folder icon
  and songs the ball.


  2026-11-19   PLAYLIST FILES IN THE FOLDERTREE
  ..........................................................................

  Preferences > Media Library > Media Library Foldertree

  Playlist files (.m3u, .m3u8, .pls, .xspf) in your folders now show in the
  right list, next to the songs. They show an icon of their own, so you can tell
  them from songs. Double-click one and every song in it is added to the
  playlist window (or played, as set for double-click).


  2026-11-19   COPY THE PLAYLIST'S FILES TO THE CLIPBOARD
  ..........................................................................

  Right-click in the Playlist window > Copy to clipboard

  Puts every song in the playlist on the clipboard, as files, the way
  Windows Explorer does when you copy them. Then open a folder in Explorer
  and press Ctrl+V: the songs are copied into the folder.

     * All the songs in the playlist are copied, not only the selected.
     * Web addresses and files that no longer exist are left out.
     * A message in the player says how many files were copied.
     * Windows only.


  2026-11-19   MEDIA LIBRARY FOLDERTREE
  ..........................................................................

  Preferences > Media Library > Media Library Type

  A second kind of Media Library, in the same window. Choose one of two:

     ( ) Media Library id3         the library as before, from the tags
     (x) Media Library Foldertree  the new one: folders and file names

  The change shows at once. You cannot choose both.

  The Foldertree library reads no tags. It only looks at folders and file
  names, and it hides the .mp3 (or .flac, and so on) at the end of a name.
  The window shows two columns:

     Left      the folders you have added
     Right     what is inside the folder you picked on the left,
               like Windows Explorer: folders first, then the songs

  How to use it

     * Press "Add folder" (at the right of "Rescan") and choose a folder.
       It appears in the left column. Right-click it to remove it again.
     * Click a folder on the left to see its contents on the right.
     * Double-click a folder on the right to open it. ".." at the top, or
       Backspace, goes back up.
     * Double-click a song to play it, or to add it to the playlist (as in
       Preferences > Media Library: "Enter and double-click enqueue").
       Play and Enqueue work on what you have selected, a whole folder too.
     * Press "Title" to sort A to Z, press again for Z to A. Press "Date
       modified" for the newest first, and again for the oldest first.
     * "Rescan" reads the folder again, if files were added meanwhile.

  The list of added folders is kept in foldertree.txt, next to the settings.


  2026-11-19   CUSTOM FONT
  ..........................................................................

  Preferences > Font

  Draw the text of the player with a font of your own. Tick "Custom font",
  choose a font from the drop-down list, and type the size you want in the
  Size box, then press OK. The change shows at once.

     [x] Custom font
     [ KROE0553.TTF            v ]   Size [ 16 ]

  The list shows the fonts in the "fonts" folder next to the program:
  .ttf, .otf and .ttc files. Put a font file there and it appears the next
  time you open Preferences. (Old bitmap fonts, .fon, cannot be used.)

  What changes

     * The font is used for the playlist, the Media Library, the menus,
       the dialogs (like Preferences itself) and for the texts of vector
       skins.
     * The size is the size of the text in the playlist and the library.
       Menus and dialogs keep their own size.
     * A classic skin's lettering on the main window (the song title and
       the little displays) is part of the skin's pictures and stays.

  If the chosen font file is taken away, Popamp shows it as "(not found)"
  and uses its usual font until you choose another.

  Custom Skin Bmp Font

  At the top of the page there is a second choice: "Custom Skin Bmp Font".
  It writes the same texts with the letters the skin itself uses for its
  small displays: the pixel lettering in the skin's Text.bmp picture,
  as in the main window of a classic skin. With the Winamp Classic Amber
  skin the playlist, the menus and the dialogs then look like the player.

     * The letters are drawn as the skin made them for sizes up to 15,
       and twice as big from size 16 (the Size box sets it).
     * Characters the picture has no letter for, such as Cyrillic, are
       written with the usual font instead.
     * It can be used on its own or together with Custom font.


  2026-11-19   WINDOWSHADE FOR THE MEDIA LIBRARY
  ..........................................................................

  The Media Library window can now roll up, like the main, equalizer and
  playlist windows. Double-click its title bar and it shrinks to a thin
  strip that shows "MEDIA LIBRARY" and keeps its close button. Double-click
  the strip, or press the small button on its right, and it opens again at
  the size it had.

  The shaded state is remembered, and it works with every skin, including
  skins that draw their own library window.


  2026-11-18   TITLE-BAR SHORTCUTS
  ..........................................................................

  Preferences > Shortcuts (under Internet)

  Decide what happens when you click, or turn the mouse wheel, on the top
  of a window: the bar you drag to move it. It works on the Main window,
  the Equalizer window and the Playlist window, both full size and in
  windowshade mode.

  Each of the six rows is built from three drop-down lists:

     [ Window ]        [ Mouse ]          [ Action ]
     Main window       Right Mouse        Previous track
     Equalizer window  Middle Mouse       Next track
     Playlist window   Scroll Up          Pause
                       Scroll Down        Stop
                                          Shuffle on/off
                                          Repeat on/off
                                          Vol Up
                                          Vol Down

  Examples

     Equalizer window + Middle Mouse + Pause
        A middle click on the equalizer's title bar pauses the music.

     Equalizer window + Scroll Up + Vol Up
        Hold the pointer over the title bar and scroll up: the volume goes
        up. The more you scroll, the more it changes. No click is needed,
        hovering is enough. Scroll Down + Vol Down does the opposite.

  Notes

     * A Right Mouse rule replaces the menu on that title bar. Without a
       rule, the menu opens as before.
     * If two rows match the same window and button, the first one counts.
     * A row set to "(nothing)" does nothing.


  2026-11-18   A SKIN COMES WITH THE PLAYER
  ..........................................................................

  Winamp Classic Amber is now the skin Popamp starts with. It is installed
  in a "skins" folder together with the program: in the Windows installer
  and the portable zip, in the Linux packages (deb and rpm) and in the
  AppImage.

  If you choose the built-in skin in the Skins menu, Popamp remembers it.
  If the skin file is ever missing, Popamp quietly uses the built-in skin
  instead of showing an error.


  2026-11-18   A "SKINS" FOLDER BESIDE THE PROGRAM
  ..........................................................................

  Put any .wsz skin in the "skins" folder next to the program and it shows
  up in the Skin Browser (Alt+S) and in the Skins menu. No installing, no
  restart.

  The Skin Browser looks at the folder again every second while it is open,
  so a skin you drop in appears at once. Skins in your user folder
  (%APPDATA%\popamp\skins on Windows) are still found, too.


  2026-11-18   VOLUME AND BALANCE IN THE SHADED EQUALIZER
  ..........................................................................

  The equalizer in windowshade mode now has volume and balance sliders,
  as in Winamp. The slider thumb changes shape with where it is in the
  range: low, middle or high.
